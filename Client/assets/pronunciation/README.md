# Pronunciation reference

MA /ma/, MI /mi/, MU /mu/. These are sounds, not letter names or translated words.
The same WAV files are embedded in every client, independent of OS locale.

Generated with eSpeak NG 1.52.0 (Spanish voice, fixed speed 120):

```
espeak-ng -v es -s 120 -w MA.wav ma
espeak-ng -v es -s 120 -w MI.wav mi
espeak-ng -v es -s 120 -w MU.wav mu
```

eSpeak NG: https://github.com/espeak-ng/espeak-ng (GPL-3.0-or-later).
Only synthesized audio is distributed here, not the synthesizer or voice data.
The Spanish voice supplies the reference vowels; students need not know Spanish.
Capture pauses throughout playback and for 500 ms after each sample.
