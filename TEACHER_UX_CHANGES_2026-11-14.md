# Изменения монитора преподавателя

14 ноября 2026. Реализовано локально; развёрнутый сервер не обновлялся.

- Выбор события синхронизирует форму решения, кадр, идентификатор и адрес страницы, даже если видео для события отсутствует. Во время сохранения смена события заблокирована.
- Черновики объяснений раздельны для событий в пределах открытой страницы. Ошибка сохранения не уничтожает объяснение. Перезагрузка страницы не сохраняет несохранённые черновики.
- Вместо четырёх немедленных действий — явный выбор исхода и сохранение. Есть подтверждение успешного сохранения, переход к следующему новому событию и история решений. Ожидающие материалов при таком переходе пропускаются.
- Разбор поддерживает камеру и запись экрана с сохранением времени при смене источника. Запоздавшие ответы для предыдущего источника или кадра игнорируются.
- Возврат из разбора ведёт к выбранной попытке. «Полный разбор» в мониторе открывает выбранный маркер, если он есть.
- Очередь разделена на новые события, ожидающие материалов и все открытые; добавлен поиск по студенту и типу. При сбое обновления сохраняются последние данные, показываются ошибка и время последнего успешного обновления.
- На промежуточной ширине окна очередь остаётся рядом с плеером; участники находятся в горизонтальном списке сверху. На узком экране сохраняется одна колонка.
- Убрана выдуманная «Основна група»; при отсутствии сведений показывается «Групу не вказано». Счётчик наблюдений больше не называется числом нарушений.
- Итоговое заключение по попытке не выбирается автоматически: требуется явный выбор преподавателя.

Проверки: 48 тестов Angular прошли в Chrome Headless; production-сборка прошла; `git diff --check -- monitor/src/app` без ошибок. Сохранились предупреждения бюджетов размера JavaScript/CSS. Визуальная проверка реального экзамена с преподавателем не проводилась.

Остаются отдельными этапами исходного отчёта: объединение итогового заключения и материалов в одну страницу попытки, единая непрерывная шкала видео с контекстом до/после события, серверный снимок правил и согласованных исключений, отдельный сценарий технической помощи, защита серверного решения от конкурентных изменений и полная проверка доступности. Эти возможности не следует считать реализованными данным изменением. Политика школы о последствиях подтверждённого нарушения не изменена.
